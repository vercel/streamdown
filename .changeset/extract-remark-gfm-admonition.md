Initial release of `remark-gfm-admonition`, a standalone Remark plugin that turns GitHub-style alert blockquotes (`> [!NOTE]`, `> [!TIP]`, `> [!IMPORTANT]`, `> [!WARNING]`, `> [!CAUTION]`) into GitHub-compatible HTML. Streamdown consumes this package internally.
